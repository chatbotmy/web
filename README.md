# Chatbot Aman & Cerdas (Web)

Aplikasi web Chatbot Aman & Cerdas berbasis **Vue 3** dan **Tailwind CSS**.
Dibuat sesuai dengan 43 desain mockup antarmuka sistem chatbot.

## Live Demo (GitHub Pages)
Aplikasi terdeploy otomatis setiap push ke branch `main`:
👉 **https://chatbotmy.github.io/web/**

## Fitur Halaman & Desain
- **Login Aplikasi** (`L-001`, `L-002`, `L-003`)
- **Ruang Chat Pengguna** (`L-005` s.d. `L-009`, `User interface 1`)
- **Metrik Sistem & Kesehatan** (`L-023`, `Dashboard Admin 1 & 2`)
- **Manajemen Peran / RBAC** (`L-010` s.d. `L-016`, `Management Peran 1 & 2`)
- **Manajemen Dokumen** (`L-017` s.d. `L-023`, `Management Dokumen 1 & 2`)
- **Master Izin Akses** (`Master Izin Akses 1`)
- **Master Klasifikasi** (`Master Klasifikasi 1`)
- **Log Audit Sistem** (`L-024`, `Tinjau Log Audit`)
- **Auditor Kepatuhan Dashboard** (`Auditor Kepatuhan Dashboard #1 & #2`)

## Menjalankan Secara Lokal
```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Build untuk production
npm run build
```
